## 🔄 Admin Workflow

### Adding a New Vehicle:

1. **Login** → `https://vehicule2-8.onrender.com/admin/login`
2. **Navigate** → Click "Vehicles" in sidebar
3. **Add New** → Click "Add New Vehicle" button
4. **Fill Details:**
   - Make, Model, Year
   - Price, Mileage, VIN
   - Condition, Fuel Type, Transmission
   - Body Type (sedan, SUV, truck, etc.)
   - Description
   - Upload Photo
   - Mark as Featured (optional)
   - Set Status (available/reserved/sold)
5. **Save** → Vehicle appears on website immediately

### Managing Reviews:

1. **Login** → Admin panel
2. **Navigate** → Click "Reviews" in sidebar
3. **View Pending** → New reviews waiting for approval
4. **Review Content** → Read customer feedback
5. **Approve** → Makes review visible on homepage
6. **Or Reject/Delete** → Removes review

### Checking Inquiries:

1. **Login** → Admin panel
2. **Navigate** → Click "Inquiries" in sidebar
3. **View All** → See customer contact requests
4. **Contact Customer** → Use provided phone/email
5. **Mark Contacted** → Track follow-up status
